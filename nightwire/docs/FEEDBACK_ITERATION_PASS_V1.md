# Feedback & Iteration Pass v1

## Purpose

This pass collects feedback, prioritizes issues and plans the next iteration.

It turns live feedback into actionable fixes.

## Feedback sources

- Player reports.
- Console errors.
- Performance telemetry.
- Mission completion data.
- Extraction success data.

## Prioritization

- P0: crash, stuck objective, broken extraction.
- P1: severe performance issue, broken interaction.
- P2: visual issue, minor UX issue.
- P3: polish, balance, optional feature.

## Iteration plan

- Fix the five worst breaks.
- Re-run QA smoke checks.
- Re-run the eight-minute vertical slice test.
- Prepare the next release.

## Next step

Create the next release after the five worst breaks are fixed.
