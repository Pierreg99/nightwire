# Content Expansion Pass v1

## Purpose

This pass expands the NIGHTWIRE content pool.

It adds missions, weapons, NPC variants and zones.

## Missions

- Cold Cargo
- Dockside Debt
- Neon Run
- Tower Watch

## Weapons

- Shotgun
- DMR

## NPC variants

- Civilian
- Crew
- Security
- Street

## Zones

- Dock District
- Neon Strip
- Plattenbau Courtyard
- Transit Tunnel
- Industrial Yard

## Integration

Import the content registry modules and use them to spawn missions, weapons, NPCs and zones.
